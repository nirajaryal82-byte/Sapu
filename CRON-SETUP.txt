24/7 SCANNER — HOW TO KEEP IT RUNNING
=====================================

Vercel Hobby (free) often does NOT allow cron every 5 minutes.
That can make the whole deployment fail.

Solution (works on free plan):

Option A — External free cron (recommended)
1. Go to https://cron-job.org  (or EasyCron / cron-job.org)
2. Create a new cron job
3. URL:  https://YOUR-PROJECT.vercel.app/api/scan-ict
4. Schedule: every 5 minutes
5. Save — this will keep the scanner running 24/7

Option B — Vercel Pro
- Upgrade to Pro
- Then add this back into vercel.json:

{
  "crons": [
    {
      "path": "/api/scan-ict",
      "schedule": "*/5 * * * *"
    }
  ]
}

After deploy, test manually:
  Open: https://YOUR-PROJECT.vercel.app/api/health
  Open: https://YOUR-PROJECT.vercel.app/api/scan-ict
